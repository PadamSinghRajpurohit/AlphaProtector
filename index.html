LOCAL SCORE + FREE BREACH CHECK

Password tester

Strength scoring runs locally. The optional exposure check uses HIBP’s free Pwned Passwords range API.

The password itself stays in this browser. The optional lookup sends only the first five characters of its SHA-1 hash to HIBP after you press the button.

Do not enter a password you currently use for a sensitive account. This tool provides an estimate, not a guarantee of safety.
